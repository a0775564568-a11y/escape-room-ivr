# הסוד של אחוזת בלקווד - חדר בריחה טלפוני

משחק חדר בריחה מלא בעברית, מופעל דרך מערכת IVR של **ימות המשיח**. השחקן מתקשר, נכנס לאחוזה מסתורית ופותר חידות במקשי הטלפון. המשחק כולל 12 חדרים, 23 חידות, פריטים לאיסוף, מעבר סודי, רמזים, ושמירת התקדמות נפרדת לכל משחק.

**כתובת השרת:** `https://escape-room-ivr.vercel.app/api/ivr`

---

## 1. מבנה הפרויקט

```text
api/ivr.js                 נקודת הקצה שימות המשיח קוראת לה
lib/game.js                סיפור, חדרים, חידות, ופתיחה/סיום, כל הטקסטים
lib/engine.js              מנוע המשחק (לוגיקה טהורה)
lib/yemot.js               בניית תגובות לפורמט של ימות המשיח
lib/audio-list.js          בדיקת קבצי השמע בתיקיית audio (מצב מתקדם)
lib/store.js               שמירת ההתקדמות ב-Hugging Face (קובץ נפרד לכל משחק)
audio/                     קובצי השמע (אפקטים נוצרים כאן אוטומטית)
scripts/test-game.js       בדיקת פתירות מלאה
scripts/generate-effects.js יצירת אפקטים קוליים
scripts/build-docs.js      יצירת VOICE_GUIDE.md ו-AUDIO_FILES.md מתוך המשחק
VOICE_GUIDE.md             כל טקסטי הקריינות של המשחק, קובץ אחר קובץ
AUDIO_FILES.md             רשימת קבצי השמע, ואיפה להעלות אותם
STORAGE_SETUP.md           הגדרת Hugging Face ומשתני סביבה
vercel.json, package.json, .env.example, .gitignore
```

---

## 2. דרישות מוקדמות

- חשבון ב-**ימות המשיח** עם שלוחה שניתן להגדיר בה `type=api`.
- חשבון ב-**GitHub** וחשבון ב-**Vercel**.
- חשבון ב-**Hugging Face** עם Dataset פרטי וטוקן עם הרשאת כתיבה. ראו `STORAGE_SETUP.md`.
- Node.js 18 ומעלה, רק לבדיקה מקומית.

אין תלויות חיצוניות, ואין צורך ב-`npm install`.

---

## 3. בדיקה מקומית

```text
npm test
```

הבדיקה מריצה את כל המשחק עם התשובות הנכונות, ומוודאת שכל 12 החדרים נפתחים ושהמשחק מסתיים. אם היא נכשלת, אל תעלו את הקוד.

ליצירת האפקטים מחדש: `npm run effects`.
לעדכון `VOICE_GUIDE.md` ו-`AUDIO_FILES.md` לאחר שינוי בטקסטים: `npm run docs`.

## 4. העלאה ל-GitHub

1. צרו מאגר חדש ב-[github.com](https://github.com) בשם `blackwood-ivr`. מומלץ **Private**.
2. אל תסמנו "Add a README".
3. העלו את כל התיקייה דרך **Add file > Upload files**, או בטרמינל:
   ```text
   git init
   git add .
   git commit -m "גרסה ראשונה"
   git branch -M main
   git remote add origin https://github.com/YOUR-USER/blackwood-ivr.git
   git push -u origin main
   ```

---

## 5. חיבור GitHub ל-Vercel

1. ב-[vercel.com](https://vercel.com) לחצו **Add New > Project** ובחרו את המאגר.
2. **Framework Preset:** בחרו **Other**. אין Build Command ואין Output Directory.
3. לפני **Deploy**, הוסיפו את משתני הסביבה מ-`STORAGE_SETUP.md`: `HF_TOKEN` ו-`HF_DATASET`.
4. ודאו שהכתובת הסופית היא `https://escape-room-ivr.vercel.app`. אם Vercel נתנה כתובת אחרת, הגדירו את שם הפרויקט ל-`escape-room-ivr` בלשונית **Settings > Domains**.

בדיקה ראשונה: פתחו בדפדפן `https://escape-room-ivr.vercel.app/api/ivr`. אמורה להופיע שורה שמתחילה ב-`read=`.

## 6. הגדרת השלוחה בימות המשיח

### 6.1 הגדרות חובה (רגיל - הקראה ב-TTS של ימות המשיח)
בשלוחה שתשמש לחדר הבריחה, הגדירו:

```text
type=api
api_link=https://escape-room-ivr.vercel.app/api/ivr
api_wait_answer_music_on_hold=yes
```

זה כל מה שצריך. בלי הגדרות נוספות, ימות המשיח מקריאה את כל הטקסטים בעצמה, בלי קבצים ובלי טוקן.

`api_wait_answer_music_on_hold=yes` משמיע מוזיקה בהמתנה בזמן שהשרת שומר את ההתקדמות ב-Hugging Face, כדי שהמתקשר לא ישמע שקט.

### 6.2 הגדרות לקריינות מתקדמת (אופציונלי - השמעה מקבצים)
כדי לעבור לקריינות מתקדמת מקבצי WAV שמועלים לשלוחה, הוסיפו שתי הגדרות נוספות:

```text
api_add_0=advanced_audio=yes
api_add_1=ym_token=הטוקן_המתקדם_שלכם
```

- `advanced_audio=yes` מפעיל את המצב המתקדם.
- `ym_token` הוא **הטוקן המתקדם** מהפאנל של ימות המשיח. זה לא מספר מערכת ולא סיסמה. הוא משמש את השרת לבדיקה שהקבצים קיימים בתיקיית `audio`. קובץ שלא נמצא מוקרא אוטומטית בהקראה רגילה, כך שהמשחק לא ייתקע.

**אזהרת אבטחה, חשוב לקרוא:** ימות המשיח שולחת את `api_add` בכל בקשה כפרמטר בכתובת (GET). לכן הטוקן יופיע בכתובת של כל בקשה. ב-Vercel, אל תשתפו את לוגי הבקשות עם אף אחד, והחליפו את הטוקן אם הוא נחשף. אם זה לא מקובל עליכם, השתמשו במצב הרגיל בלבד.

### 6.3 תיקיית השמע
במצב המתקדם, צרו **בתוך השלוחה** תיקייה בשם `audio`, והעלו לתוכה את כל הקבצים מ-`AUDIO_FILES.md`. לדוגמה, אם השלוחה היא `/3`, הקבצים ב-`/3/audio/`. שמות הקבצים מדויקים, כולל אותיות גדולות וקטנות.

השרת מזהה את שם השלוחה מתוך הפרמטר `ApiExtension` שימות המשיח שולחת. לכן חשוב שהתיקייה `audio` תהיה בתוך השלוחה שבה הוגדר המודול.

### 6.4 אחרי כל שינוי בשלוחה
שמרו את השלוחה ובדקו בשיחת ניסיון לפי סעיף 7.

## 7. בדיקת הגדרות בטלפון

1. התקשרו למספר של השלוחה. תישמע פתיחת הסיפור ואז התפריט הראשי.
2. הקישו `2` ואז `#`. נפתחת מפת החדרים.
3. הקישו `1` ואז `#`. נכנסים לחדר 1 ונשמעת החידה הראשונה.
4. הקישו `0` ואז `#`. נשמעת הודעת שגיאה, וההקשה חוזרת.
5. הקישו `99` ואז `#`. נשמע רמז.
6. הקישו `15` ואז `#`. נשמע המשך הסיפור, ונפתחת החידה הבאה.
7. הקישו `*`. חוזרים למפת החדרים.

**חשוב לבדוק במיוחד:**
- שההקשה מתקבלת ונשמעת פעם אחת בלבד, ולא נתקעת.
- במצב המתקדם: שבשלוחה נשמע קובץ השמע (ולא הקראה) עבור קובץ שהועלה.
- במצב המתקדם: שקובץ שלא הועלה מוקרא בהקראה ולא נתקע.

**הערה על פורמט:** השרת שולח לימות המשיח פקודה בפורמט `read=...=in,,1,4,Digits,no`, ושרשרת קטעים מחוברים בנקודה. פורמט הרצף נלקח מהתיעוד של ימות המשיח לפקודות השמעה, אך מומלץ לוודא אותו בשיחת הניסיון. אם השמעה לא עובדת כראוי, פתחו את `lib/yemot.js` ובדקו את הפונקציה `readAction`.

## 9. איך משחקים

- **תפריט ראשי:** `1` להמשך משחק שמור, `2` למשחק חדש, `3` להוראות.
- **חידה:** הקלידו את התשובה ואז `#`.
- **רמז:** `99` ואז `#`. אחרי שלוש טעויות, נשמע רמז אוטומטית.
- **מפה:** הקישו את מספר החדר ואז `#`. מוצגים רק חדרים זמינים.
- **חזרה לתפריט:** `*`.

חדר נפתח רק כשאוספים את הפריטים שלו מחדרים קודמים. כדאי לחזור לחדרים שכבר פתחתם ולבדוק מה נפתח.
